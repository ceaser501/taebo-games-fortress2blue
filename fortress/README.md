# Fortress

포트리스2 블루 스타일의 턴제 포격 게임 (브라우저, HTML5 Canvas). 개발 서버에서는 `/fortress/`로 열립니다.

## 실행

저장소 루트에서:

```bash
npm install
npm run fortress:assets -- ../taebo-games-fortress2blue-assets   # 원본 데이터 변환 (최초 1회)
npm start                                                         # 개발 서버
```

변환 결과(`fortress/assets/f2/`)가 없으면 게임이 시작되지 않습니다.

## 규칙

- 1:1 턴제. 턴마다 20초. 10초부터 숫자가 빨갛게 흔들리며 똑딱 소리가 납니다.
- 턴마다 바람이 바뀝니다 (패널의 WIND).
- 턴마다 움직일 수 있는 양이 정해져 있습니다 (패널의 Move).
- 포탄은 땅을 파고, 발밑 땅이 없어지면 떨어집니다. 높이 떨어지면 체력이 깎이고, 맵 바닥 아래는 물이라 빠지면 죽습니다.
- 체력(Energy)이 0이 되거나 물에 빠지면 집니다.

원작 캐릭터 선택 화면 그대로 12종을 고릅니다. **?** 칸은 무작위이고, 약 4% 확률로 선택 화면에 없는 **슈퍼탱크**가 나옵니다.
탱크마다 방어력(받는 데미지), 이동력(Move 게이지), 각도 범위가 다르고, 선택 화면의 막대로 보입니다(왼쪽 나, 오른쪽 상대).

| 탱크 | 1번 | 2번 |
|---|---|---|
| 카타펄트 | 짱돌 | 불덩어리 돌 |
| 크로스보우 | 화살 | 독화살 |
| 캐논 | 검콩 | 빨콩 |
| 캐롯 | 탱크포 | 녹색 포탄 3발 |
| 듀크 | 탱크포 | 독가스탄 |
| 미사일 | 빨간 미사일 | 녹색 유도탄 |
| 멀티 미사일 | 로켓 3발 | 로켓 9발 |
| 레이저 | 레이저탄 | 레이저 연사 |
| 마인 랜더 | 유탄 | 지뢰 2개 |
| 아이온 어태커 | 에너지탄 | 위성탄 |
| 포세이돈 | 물덩어리 | 큰 물덩어리 |
| 세크윈드 | 에너지탄 | 회전 에너지탄 2발 |
| 슈퍼탱크 | 3연발 미사일 | 9연발 유도탄 |

무기 구성은 나무위키 '포트리스2/등장탱크'를 따랐고(레이저는 문서에 없어 임의), 탱크 이름은 선택 화면 이름표 순서로, 포탄 그림은
원작 실행 파일(libmain.so) 안의 표에서 그대로 가져왔습니다: 무기마다 포탄 그림, 발사음, 폭발음. 유도탄(녹색 유도탄, 9연발 유도탄)은
날아가다 0.6초 뒤부터 가장 가까운 적 쪽으로 꺾입니다.
수치는 `js/tanks.js`에 있습니다.

## 온라인 대전

메뉴의 **친구와 온라인 대전**에서 이름을 적고, 한 명이 **방 만들기**를 누르면 대기실이 열립니다.
친구가 5자리 방 코드로 **참가**하면 대기실에 이름과 탱크가 뜨고(알림음), 방장이 **게임 시작**을 누르면 시작합니다.
로그인은 없습니다. 각자 위의 선택 화면에서 고른 탱크로(? 는 방장 쪽에서 굴림) 방장이 고른 맵에서 1:1(방장 빨강, 친구 파랑)입니다.
판이 끝나면 방장이 **다시 하기**나 **대기실로**를 고릅니다. 채팅도 서로 보입니다.

- 웜즈와 같은 방식입니다: Supabase Realtime 채널(웜즈와 같은 프로젝트, 채널 이름 앞 `tbfortress-`)로 broadcast와 presence만 씁니다.
  설정은 `js/net.js` 맨 위입니다.
- 방장 화면이 게임을 계산하고 친구 화면에 상태를 초당 20번 보냅니다. 친구의 입력은 방장에게 전달됩니다.

## 아이템

웜즈와 같은 아이템 중 5가지입니다(바람 멈춤은 뺌). 한 판에 정해진 개수만큼, 쏘기 전에 쓰고, 한 턴에 여러 개를 겹쳐 쓸 수 있습니다.

| 키 | 아이템 | 개수 | 효과 |
|---|---|---|---|
| Q | 2연발 | 2 | 같은 각도·세기로 0.5초 뒤 한 발 더 |
| W | 공격력 2배 | 2 | 이번 턴 데미지 2배 |
| E | 파워샷 | 3 | 발사 속도 1.3배, 데미지 1.3배 |
| T | 체력 회복 | 1 | 체력 +40 (최대 100) |
| Y | 순간이동 | 1 | 누른 곳으로 이동, 턴 끝 |

패널의 아이템 칸을 눌러도 됩니다. 수치는 `js/items.js`에 있습니다.
아이콘은 웜즈 클론과 같은 그림으로, 자산 저장소의 `Worms/items/`에서 변환기가 가져옵니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↑ ↓ | 각도 (짧게 누르면 1도) |
| Space | 누르고 있다가 떼면 발사 (패널의 Power, 노란 ▼는 지난번 세기) |
| 1 / 2 / Tab | 1번·2번 공격 (패널의 FIRE1·FIRE2를 눌러도 됨) |
| 마우스 드래그 | 화면 이동 |
| 휠, + - | 확대·축소 |
| Esc | 메뉴 |

폰에서는 왼쪽에 방향 버튼, 오른쪽에 1번·2번·발사 버튼이 나옵니다. 한 손가락으로 끌면 화면 이동, 두 손가락으로 확대·축소.

## 화면

아래쪽 패널과 턴 시간 숫자는 원작 그림입니다. PC판처럼 화면 아래를 꽉 채우도록, 원작 오락실 패널 그림을
칸 단위로 다시 조립합니다(아이템 칸 6개, DELAY를 빼고 두껍게 만든 WIND, 긴 Energy·Power·Move). 이 화면의 사람(컴퓨터 상대일 때는 나,
한 화면 2인일 때는 지금 차례인 사람)의 패널을 띄웁니다. 오른쪽 위는 미니맵입니다.

- 컴퓨터: 패널 오른쪽에 채팅창 (Enter로 입력, 게임 소식도 여기에)
- 맵 지형은 물 라인에서 끝나고, 물 수면이 하단 막대 윗선에 맞습니다(웜즈처럼). 막대 아래와 폰의 양쪽 구석은 물로 채워집니다.
- 폰: 패널은 가운데에 크게 두고(TURN 칸은 빼고, 누구 차례인지는 안내 문구로), 양쪽 구석에 조금 작게 방향키와 웜즈와 같은 발사·1번(점프 자리)·2번(백덤블링 자리) 버튼.
  채팅은 위쪽 채팅 버튼으로 쓰고, 방향키 위에 잠깐 떴다 사라집니다.
- 화면은 기기 해상도(최대 2배)로 그리고, 패널 그림은 정수 배율로 키운 뒤 부드럽게 줄여서 깨짐 없이 보이게 합니다.

| 패널 칸 | 내용 |
|---|---|
| 각도기 | 바늘과 숫자가 지금 각도 |
| FIRE1 / FIRE2 | 1번·2번 포탄 그림 (캐논은 검콩·빨콩), 고른 쪽에 불이 켜짐 |
| 아이템 6칸 | 웜즈식 카드: 아이콘·이름·남은 개수 배지, 이번 턴에 쓴 것은 노란 테두리 (순간이동은 내 탱크 그림) |
| WIND | 바람 방향·세기 (가운데 눈금에서 늘어남), 오른쪽 끝에 숫자. 원작의 DELAY 줄은 빼고 WIND 막대를 그 두께로 키움 |
| Energy / Power / Move | 체력 / 발사 세기 / 남은 이동량 |

## 효과음

무기별 발사음·폭발음은 원작 실행 파일의 효과음 표대로입니다(`js/tanks.js`). 그 밖의 공용 소리는 길이와 소리 모양으로 짐작했습니다(`js/audio.js`의 `SFX`).
주소 끝에 `?sfx`를 붙여 열면 55개를 하나씩 들어 볼 수 있습니다.
