# Fortress

포트리스2 블루 스타일의 턴제 포격 게임 (브라우저, HTML5 Canvas). 개발 서버에서는 `/fortress/`로 열립니다.

## 실행

저장소 루트에서:

```bash
npm install
npm run fortress:assets -- ../taebo-games-fortress2blue-assets   # 원본 데이터 변환 (최초 1회)
npm start                                                         # 개발 서버
```

변환 결과(`fortress/assets/f2/`)가 없으면 게임이 시작되지 않습니다.

## 규칙

- 1:1 턴제. 턴마다 20초. 10초부터 숫자가 빨갛게 흔들리며 똑딱 소리가 납니다.
- 턴마다 바람이 바뀝니다 (패널의 WIND).
- 턴마다 움직일 수 있는 양이 정해져 있습니다 (패널의 Move).
- 포탄은 땅을 파고, 발밑 땅이 없어지면 떨어집니다. 높이 떨어지면 체력이 깎이고, 맵 바닥 아래는 물이라 빠지면 죽습니다.
- 체력(Energy)이 0이 되거나 물에 빠지면 집니다.

| 탱크 | 1번 | 2번 |
|---|---|---|
| 캐논 | 포탄 | 불덩이 (바람을 덜 타고 크게 터짐) |
| 카롯 | 당근 미사일 (바람을 많이 탐) | 당근 3발 (부채꼴) |
| 카타펄트 | 돌덩이 (큰 구멍) | 튕기는 불돌 (한 번 튀고 터짐) |
| 크로스보우 | 화살 (직선에 가깝고 아픔) | 화살 연사 (3발) |

수치는 `js/tanks.js`에 있습니다.

## 아이템

웜즈와 같은 6가지입니다. 한 판에 정해진 개수만큼, 쏘기 전에 쓰고, 한 턴에 여러 개를 겹쳐 쓸 수 있습니다.

| 키 | 아이템 | 개수 | 효과 |
|---|---|---|---|
| Q | 2연발 | 2 | 같은 각도·세기로 0.5초 뒤 한 발 더 |
| W | 공격력 2배 | 2 | 이번 턴 데미지 2배 |
| E | 파워샷 | 3 | 발사 속도 1.3배, 데미지 1.3배 |
| R | 바람 멈춤 | 2 | 이번 턴 바람 0 |
| T | 체력 회복 | 1 | 체력 +40 (최대 100) |
| Y | 순간이동 | 1 | 누른 곳으로 이동, 턴 끝 |

패널의 아이템 칸을 눌러도 됩니다. 수치는 `js/items.js`에 있습니다.
아이콘은 웜즈 클론과 같은 그림으로, 자산 저장소의 `Worms/items/`에서 변환기가 가져옵니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↑ ↓ | 각도 (짧게 누르면 1도) |
| Space | 누르고 있다가 떼면 발사 (패널의 Power, 노란 ▼는 지난번 세기) |
| 1 / 2 / Tab | 1번·2번 공격 (패널의 FIRE1·FIRE2를 눌러도 됨) |
| 마우스 드래그 | 화면 이동 |
| 휠, + - | 확대·축소 |
| Esc | 메뉴 |

폰에서는 왼쪽에 방향 버튼, 오른쪽에 1번·2번·발사 버튼이 나옵니다. 한 손가락으로 끌면 화면 이동, 두 손가락으로 확대·축소.

## 화면

아래쪽 패널과 턴 시간 숫자는 원작 그림입니다. PC판처럼 화면 아래를 꽉 채우도록, 원작 오락실 패널 그림을
칸 단위로 다시 조립합니다(아이템 칸 6개, DELAY를 빼고 두껍게 만든 WIND, 긴 Energy·Power·Move). 이 화면의 사람(컴퓨터 상대일 때는 나,
한 화면 2인일 때는 지금 차례인 사람)의 패널을 띄웁니다. 오른쪽 위는 미니맵입니다.

- 컴퓨터: 패널 오른쪽에 채팅창 (Enter로 입력, 게임 소식도 여기에)
- 맵 지형은 물 라인에서 끝나고, 물 수면이 하단 막대 윗선에 맞습니다(웜즈처럼). 막대 아래와 폰의 양쪽 구석은 물로 채워집니다.
- 폰: 패널은 가운데에만 두고, 양쪽 구석은 맵이 보이게 비워 둡니다. 왼쪽 아래에 방향키, 오른쪽 아래에 웜즈와 같은 발사·1번(점프 자리)·2번(백덤블링 자리) 버튼.
  채팅은 위쪽 채팅 버튼으로 쓰고, 방향키 위에 잠깐 떴다 사라집니다.
- 화면은 기기 해상도(최대 2배)로 그리고, 패널 그림은 정수 배율로 키운 뒤 부드럽게 줄여서 깨짐 없이 보이게 합니다.

| 패널 칸 | 내용 |
|---|---|
| 각도기 | 바늘과 숫자가 지금 각도 |
| FIRE1 / FIRE2 | 고른 공격에 불이 켜짐 |
| 아이템 6칸 | 아이콘, 남은 개수, 이번 턴에 쓴 것은 노란 테두리 |
| WIND | 바람 방향·세기 (가운데 눈금에서 늘어남), 오른쪽 끝에 숫자. 원작의 DELAY 줄은 빼고 WIND 막대를 그 두께로 키움 |
| Energy / Power / Move | 체력 / 발사 세기 / 남은 이동량 |
| TURN | 내 차례면 내 색 |

## 효과음

원본 효과음 파일에 이름이 없어서 길이와 소리 모양으로 짐작해 넣었습니다(`js/audio.js`의 `SFX`).
주소 끝에 `?sfx`를 붙여 열면 55개를 하나씩 들어 볼 수 있습니다.

## 구조

| 파일 | 내용 |
|---|---|
| `js/game.js` | 턴, 이동, 포탄 물리, 폭발, 카메라, 그리기 (패널·턴 시간 포함) |
| `js/terrain.js` | 부서지는 지형 (마스크 + 캔버스) |
| `js/tanks.js` | 탱크와 공격 수치 |
| `js/items.js` | 아이템과 아이콘 |
| `js/ai.js` | 컴퓨터 (실제 물리로 궤적을 계산해 조준) |
| `js/audio.js` | 원본 효과음, 턴 시간 소리 합성 |
| `js/music.js` | 배경음악 (원본 OGG 12곡 중 무작위) |
| `js/assets.js` | 변환된 에셋 로더 |
| `tools/` | 원본 데이터 변환기 (루트 README 참고) |
